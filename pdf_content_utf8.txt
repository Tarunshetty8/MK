5. Back end API Specific ations 
5.1 API Architecture 
•
 RESTful API design 
•
 JSON request/response format 
•
 Authentication: JWT tokens (Bearer token in Authorization header) 
•
 API versioning: /api/v1/... 
•
 Rate limiting: 100 requests per minute per IP/user  
5.2 Core Endpoints 
Authen tication 
Method Endpoint Description 
POST /api/auth/register User signup (email, password, name) 
POST /api/auth/login User login, returns JWT token 
POST /api/auth/logout Invalidate JWT token 
POST /api/auth/reset-password Request password reset email 
 
CONFIDENTIAL — Internal Development Use Only Marmelo Kitchen — Technical Requirements Document  |  Version 1.0 
Products 
Method Endpoint Description 
GET /api/products List all products (supports filters, search, pagination) 
GET /api/products/:id Get single product details 
POST /api/products Create new product (admin only) 
PUT /api/products/:id Update product (admin only) 
DELETE /api/products/:id Delete product (admin only) 
 
Orders 
Method Endpoint Description 
GET /api/orders List user's orders (customer) or all orders (admin) 
GET /api/orders/:id Get order details 
POST /api/orders Create new order (checkout) 
PATCH /api/orders/:id/status Update order status (admin only) 
 
Catering & Venue Enquiries 
Method Endpoint Description 
POST /api/catering/enquiries Submit catering enquiry 
POST /api/venue/enquiries Submit venue hire enquiry 
GET /api/enquiries List all enquiries (admin only) 
PATCH /api/enquiries/:id/status Update enquiry status (admin only) 
 
User Profile 
Method Endpoint Description 
GET /api/profile Get current user's profile 
PUT /api/profile Update profile information

6. Security & Compliance 
6.1 Data Security 
•
 All passwords hashed using bcrypt (min cost factor 10) 
•
 HTTPS enforced (SSL/TLS certificate) 
•
 Secure storage of API keys and secrets (environment variables, not hardcoded) 
•
 SQL injection prevention: Use parameterized queries/ORM 
•
 XSS protection: Sanitize all user inputs 
•
 CSRF protection: CSRF tokens for state-changing requests  
6.2 Payment Security 
•
 PCI DSS compliance: Do NOT store card details — use Stripe/Razorpay tokenization 
•
 Payment webhooks: Verify webhook signatures to prevent fraud  
6.3 GDPR Compliance (if applicable) 
•
 Cookie consent banner on website 
•
 Privacy policy and terms of service pages 
•
 User data export: Allow users to download their data 
•
 Right to deletion: Implement user account deletion feature
